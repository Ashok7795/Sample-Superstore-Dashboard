# Sample-Superstore-Dashboard( Interactive Dashboard Creation Using MS Excel)
## Project Objective
The primary goal of this project is to analyze the performance of products across different dimensions, including Model, Category, Sub-Category, Region, and Symbol. The project aims to identify trends, patterns, and performance insights by analyzing data over days, months, and years.
## Dataset Used
- <a href="https://github.com/Ashok7795/Sample-Superstore-Dashboard/blob/main/Sample%20-%20Superstore.xls">Dataset</a>
## Data description
•	Orders — the core transactional dataset, containing 9,994 order line items with customer, product, sales and profit details.
•	People — maps each of the four sales regions (Central, East, South, West) to its Regional Manager.
•	Returns — a list of 800 order IDs that were returned by customers.
•	KPI / Sheet1 / Sheet2 — supporting calculation sheets used to build summary metrics for the dashboard.
•	Report — the final dashboard/report sheet containing the charts and KPI cards.
## Questions (KPIs)
- Total sales By region
- Average sales by category
- Total orders by category and shipment mode
- Top 10 products
- Total orders by shipment mode
- Show how much sales has been done by each category
- Create the chart to display profit over months

##Cleaning Process

The dataset was cleaned and prepared before visualization to ensure accuracy and consistency.

The following data preprocessing steps were performed:

- Imported the dataset into Power BI.
- Verified data types for all columns.
- Converted Order Date and Ship Date into Date format.
- Removed duplicate records, if any.
- Checked for missing or null values.
- Corrected inconsistent data formats.
- Renamed column headers where necessary for better readability.
- Created a Date hierarchy for Year, Quarter, Month, and Day analysis.
